# Extension icon

The blue folder is an SVG recreation of the Arc Live Folder reference. The white GitHub mark is copied from the installed Arc application's `ARCClients_BaseAssets.bundle/Contents/Resources/github-white.svg` and preserved in `github-mark.svg`.

`icon.svg` is the source for the 48 and 128 px exports. `icon-small.svg` uses a slightly larger mark and heavier outlines for the 16 and 32 px toolbar exports. The PNGs have transparent backgrounds and are rendered directly from these vectors with macOS AppKit.
